Detailed Description

template<typename ValueType, dftefe::utils::MemorySpace memorySpace>
class dftefe::ksdft::RDM1Access< ValueType, memorySpace >

Resource Acquisition Is Initialization (RAII) wrapper that temporarily holds the SpectralRep moved out of an RDM1Spectral. On destruction (or returnBack()) the rep is returned via setSpectral().
